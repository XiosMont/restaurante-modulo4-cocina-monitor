# Módulo 4: Cocina y Monitor

Este repositorio corresponde al Módulo 4 del Sistema de Gestión de Restaurante (Asignatura Ingeniería de Software TI3043).

## Descripción del módulo

El Módulo 4 recibe los pedidos confirmados desde el Módulo 3 de Pedidos, los muestra en una cola de cocina y permite al cocinero marcar los pedidos como **EN_PREPARACIÓN** o **LISTO**.  
Cuando un pedido se marca como LISTO, el módulo notifica al Módulo 3 para que continúe el flujo hasta **ENTREGADO** y **CERRADO**.

## Objetivo del Sprint 1

Definir el modelo de datos y los contratos de comunicación (endpoints API), junto con la planificación inicial en Taiga (backlog, épicas, historias y UML) para poder implementar los CRUD en el siguiente sprint.
